# Frontend

The React/Vite frontend for CodeTrack. See the [repository setup guide](../README.md) and [migration/publication notes](../MIGRATION_AND_PUBLICATION.md).

Run `npm ci`, configure `.env` from `.env.example`, then `npm run dev`. Use `npm run lint` and `npm run build` before deployment. Set `VITE_API_BASE_URL` to the backend base URL including `/api`.
